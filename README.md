# Seng Garcia — Portfolio

Editable static resume portfolio with smooth reveal animations, responsive layout, and persistent light/dark mode.

Edit `index.html` for content, `styles.css` for visuals, and `script.js` for interactions. Replace the photo placeholder with an image when ready. Only repository collaborators can edit the source; visitors can view the published GitHub Pages site.

Run locally with `python3 -m http.server 8000`.
